Odido

Together with the ACT agency, we contributed to the go-live of the rebrand: Odido, and that was not a matter of one studio delivering something. We worked in secret, together with other production houses like BUCK and Code d'Azur, all building the same brand at the same time. To create something really cool together.

How we did that?

That requires a different way of working. Go through the Brandbook, follow exactly where it should be, and add that little bit of your own input where there was room. Everything had to flow together seamlessly, even if it came from different studios. We call them thinking makers.

Explanation animations

For Odido we made explanation animations for the website around the go-live and internal videos to get the team excited about the rebrand.
